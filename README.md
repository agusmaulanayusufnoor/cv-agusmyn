# cv-agusmyn

Curriculum Vitae & Engineering Portfolio of **Agus Maulana Yusuf Noor** (Head of IT Department & Lead Engineer).

Built with **Bun**, **Hono**, and **Tailwind CSS**.

## ✨ Features
- **Bilingual Support (EN / ID)** via `?lang=en` and `?lang=id`
- **Automated GitHub API Sync** with Bun in-memory cache
- **Machine-readable JSON API** at `/api/cv` and `/api/github/repos`
- **ATS-Friendly Print & PDF Export** (`window.print()` with `@media print`)
- **Spatial Glassmorphism & Micro-Interactions**

## 🚀 Quick Start

```sh
# Install dependencies
bun install

# Run development server
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
